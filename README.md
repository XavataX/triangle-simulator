# Simulator trougla 2.0.20 — GitHub Pages PWA

Upload the CONTENTS of this folder to the root of your existing GitHub repository, replacing index.html, sw.js, manifest.webmanifest and keeping icons/ and .nojekyll. Commit. In Settings → Pages set main → /(root). Once deployment completes, reload the public URL and select **Ažuriraj** when offered.

The app works offline after loading through an HTTPS site and successful caching; the standalone HTML does not require hosting.

## Canvas interaction

Double-click or double-tap a displayed angle to enter degrees and minutes directly there; Enter confirms, Escape cancels. Clear the field and press Enter to unlock the given. Existing touch zoom/pan and point renaming remain available. Multiple given angles are restricted to two independent values; a third is calculated. With active given values, free vertex dragging is temporarily blocked so it cannot invalidate the assignment. Use **Više alata → ↺ Zadati uglovi** to free geometry.
